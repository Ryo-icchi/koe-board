# こえ — 文字盤と読み上げアプリ

口の麻痺などで**声が出せないが、文字は読めて意識もはっきりしている方**（構音障害・発話障害）のための、iPhone / iPad 用コミュニケーションアプリです。紙の50音表を指差しする代わりに、画面をタッチして文章を組み立て、**端末が声で読み上げ**ます。

> ※ 言語そのものを失う「失語症」向けの絵・シンボル中心アプリとは別物です。文字が読める方向けに「かな文字盤＋読み上げ＋定型文」に特化しています。

## できること

- **定型文を1タップで読み上げ** — よく使う言葉（はい/いいえ/トイレ/痛い/水がほしい 等）をカテゴリ別に搭載
- **50音の文字盤で自由に文章を作る** — 紙の文字盤と同じ並び（あ列が右・縦にあいうえお）。濁点・半濁点・小文字・句読点も対応
- **読み上げ（音声合成）** — 家族だけでなく看護師さんや電話越しにも声で伝わる
- **定型文の追加・編集・削除** — 「✏️ ことばを編集」ボタンから。おじいさま専用の言葉（家族の名前・薬・かかりつけ等）を自由に登録
- **文字サイズ変更**（小・中・大）
- **オフライン動作・無料** — ホーム画面に追加すればアプリのように使えます

## 使い方

1. ホーム画面のアイコンから起動
2. 上のタブでカテゴリを選び、言葉をタップ → 大きく表示され、声で読み上げます
3. 自分で文章を作るときは「🔤 もじ」タブで1文字ずつタップ → 「🔊 よみあげ」
4. 言葉を増やす・直すときは下の「✏️ ことばを編集」→ 各言葉をタップして編集／削除、「＋ ことばを追加」で新規追加

> 登録した言葉は**その端末の中だけ**に保存されます（外部に送信されません）。

## iPhone / iPad へのインストール（ホーム画面に追加）

1. Safari でアプリのURLを開く
2. 共有ボタン（□から↑）→「ホーム画面に追加」
3. 追加したアイコンから起動するとフルスクリーンで使えます

## 定型文の出典・設計

初期搭載の定型文は、ICU・ベッドサイド・在宅介護で使われるコミュニケーションボードのベストプラクティス（基礎語彙＝はい/いいえ/痛い/トイレ/水/止めて/ありがとう、および「体調」「してほしいこと」「痛みの場所」「気持ち」のカテゴリ分類）を、日本の高齢者向けに翻案したものです。家族で自由に編集してください。

## 技術メモ（開発用）

- 素の HTML / CSS / JS（ビルドなし）の PWA。`index.html` / `app.js` / `manifest.json` / `sw.js` / `icon-*.png`
- 読み上げ: Web Speech API（`speechSynthesis`、ja-JP）。iOS Safari は端末内蔵の日本語音声を使用
- 定型文は `localStorage`（キー `koe.phrases.v1`）に保存。初期値は `app.js` の `DEFAULT_PHRASES`
- 更新時は `sw.js` の `CACHE` バージョンを上げる（cache-first のため）
- E2E テスト: `node test-e2e.mjs`（ヘッドレス Chrome / CDP・17項目）
