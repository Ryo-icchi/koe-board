# こえ文字盤 — 文字を選んで声で伝えるアプリ

口の麻痺などで**声が出せないが、文字は読めて意識もはっきりしている方**（構音障害・発話障害）のための、iPhone / iPad 用コミュニケーションアプリです。紙の50音表を指差しする代わりに、画面をタッチして文章を組み立て、**端末が声で読み上げ**ます。

> ※ 言語そのものを失う「失語症」向けの絵・シンボル中心アプリとは別物です。文字が読める方向けに「かな文字盤＋読み上げ＋定型文」に特化しています。

## できること

- **定型文を1タップで読み上げ** — よく使う言葉（はい/いいえ/トイレ/痛い/水がほしい 等）をカテゴリ別に搭載
- **50音の文字盤で自由に文章を作る** — 紙の文字盤と同じ並び（あ列が右・縦にあいうえお）。**1文字タップするとその音をすぐ読み上げる**ので押し間違いに気づきやすい
- **濁点・半濁・小文字・ー を大きなキーで盤に配置** — 「あいうえお」と同じ大きさ。わ・を・ん を上に詰めて空いたところに置いた
- **「濁音・半濁・小」タブ** — が／ぱ／きゃ などを**1タップで直接入力**（「き→や→小」と押す手間なし）。紙の文字盤の濁音・半濁音・拗音コーナーを並び順・配色（濁音=暖色／拗音=緑、行ごとに交互色でグルーピング）まで再現
- **読み上げ・けす・ぜんぶ消す のボタンを大きく** — 押しやすく見やすい
- **定型文・カテゴリの並び替え** — 言葉やタブを**長押し（約0.5秒）するとドラッグで移動**できる（編集モードのON/OFFどちらでも可）
- **定型文の追加・編集・削除** — 「✏️ ことばを編集」ボタンから。おじいさま専用の言葉（家族の名前・薬・かかりつけ等）を自由に登録
- **文字サイズ変更**（小・中・大）
- **オフライン動作・無料** — ホーム画面に追加すればアプリのように使えます

## 使い方

1. ホーム画面のアイコンから起動
2. 上のタブでカテゴリを選び、言葉をタップ → 大きく表示され、声で読み上げます
3. 自分で文章を作るときは「🔤 もじ」タブで1文字ずつタップ → 「🔊 よみあげ」
   - が・ぱ・きゃ など濁音／半濁音／小さい文字は「濁音・半濁・小」タブで1タップ入力
4. 言葉を増やす・直すときは下の「✏️ ことばを編集」→ 各言葉をタップして編集／削除、「＋ ことばを追加」で新規追加

> 登録した言葉は**その端末の中だけ**に保存されます（外部に送信されません）。

## 登録した言葉・並び順はアプリ更新で消える？

**消えません。** 自分で追加した定型文や、長押しで並べ替えた順番・文字サイズの設定は端末内（`localStorage`）に保存され、アプリ（このコード）のバージョンが上がっても**そのまま残ります**。更新で入れ替わるのはアプリ本体のファイルだけで、登録データには触れません。初期の定型文に戻るのは「まだ一度も自分で編集していないとき」だけです。

ただし次の場合は端末の仕様上データが消えます（アプリ側では防げません）:

- **ホーム画面に追加せず Safari のタブのまま**使い、1週間ほど開かない（iOSが未使用サイトのデータを自動削除する） → **必ず「ホーム画面に追加」して、そのアイコンから使えば消えません**
- Safari の履歴・Webサイトデータの消去、端末の初期化、別の端末への買い替え

大事な言葉を確実に守りたい場合は、別端末にも移せる**バックアップ（書き出し／読み込み）機能**を付けられます（現状は未実装・必要なら追加します）。

## iPhone / iPad へのインストール（ホーム画面に追加）

1. Safari でアプリのURLを開く
2. 共有ボタン（□から↑）→「ホーム画面に追加」
3. 追加したアイコンから起動するとフルスクリーンで使えます

## 定型文の出典・設計

初期搭載の定型文は、ICU・ベッドサイド・在宅介護で使われるコミュニケーションボードのベストプラクティス（基礎語彙＝はい/いいえ/痛い/トイレ/水/止めて/ありがとう、および「体調」「してほしいこと」「痛みの場所」「気持ち」のカテゴリ分類）を、日本の高齢者向けに翻案したものです。家族で自由に編集してください。

## 技術メモ（開発用）

- 素の HTML / CSS / JS（ビルドなし）の PWA。`index.html` / `app.js` / `manifest.json` / `sw.js` / `icon-*.png`
- 読み上げ: Web Speech API（`speechSynthesis`、ja-JP）。iOS Safari は端末内蔵の日本語音声を使用
- 定型文は `localStorage`（キー `koe.phrases.v1`）に保存。初期値は `app.js` の `DEFAULT_PHRASES`。**並び順も同じオブジェクトのキー順／配列順で保持**するため、別キーは増やしていない（＝更新でユーザーデータは消えない。SWが消すのは `caches` のアプリ本体だけ）
- 50音タップ・濁点トグルでその文字を読み上げる（`speak()`）
- 並び替えは長押し（450ms）→ Pointer Events でドラッグ。`enableLongPressReorder()`。「もじ」タブは固定（`.tab.cat` のみ対象）
  - 縦ドラッグがネイティブスクロールに奪われる問題は、ドラッグ中だけ `touchmove` を `preventDefault`（`{passive:false}`）して抑止。端でリストを自動スクロールするので画面外の項目にも届く（`startDrag`）
- Service Worker は **HTML と app.js（コード）= ネットワーク優先 / アイコン等 = キャッシュ優先**のハイブリッド。iOSホーム画面PWAは純 cache-first だと更新が永久に届かないため（resume≠reload・「次々回起動」問題）。これによりオンラインなら1回の起動で最新が届く
- 更新時は `sw.js` の `CACHE` バージョンも上げる（旧キャッシュ削除のトリガー）
- E2E テスト: `node test-e2e.mjs`（ヘッドレス Chrome / CDP・並び替え含む全項目）
